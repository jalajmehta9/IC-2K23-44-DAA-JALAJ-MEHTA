# Data Structures and Algorithms Lab Practicals (Python)

This repository contains Python 3 implementations of basic **Data Structures and Algorithms (DSA)** practicals. It covers array operations and sparse matrix representation with commonly used operations.

## 📚 Practicals Included

### 1. One-Dimensional Array Operations
**File:** `1D_Array.py`

Operations:
- Insert an element at a specified position.
- Delete an element from a specified position.
- Search for an element.
- Rotate the array to the left.
- Rotate the array to the right.
- Display the array.

### 2. Two-Dimensional Array Operations
**File:** `2D_Array.py`

Operations:
- Insert a row.
- Delete a row.
- Insert a column.
- Delete a column.
- Search for an element.
- Rotate the matrix by 90 degrees clockwise.
- Display the matrix.

### 3. Sparse Matrix Representation
**File:** `Sparse_Matrix.py`

Operations:
- Represent a sparse matrix using triplet representation.
- Convert a normal matrix into triplet form.
- Display the sparse matrix.
- Display the original matrix.
- Find the transpose of a sparse matrix.
- Add two sparse matrices.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Concepts:** Arrays, Matrices, Sparse Matrices, Searching, Insertion, Deletion, Rotation, Transpose, Matrix Addition.

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd DSA-Lab-Practicals
   ```

3. Run the desired practical:

   **1D Array**
   ```bash
   python 1D_Array.py
   ```

   **2D Array**
   ```bash
   python 2D_Array.py
   ```

   **Sparse Matrix**
   ```bash
   python Sparse_Matrix.py
   ```
